# Projects

A collection of personal projects.

## [SSBUScraper](./SSBUScraper)
I've been playing lots of SSBU with my dorm mates recently and I was curious about the relationship between a character's average matchup scores and their perceived rank on the tier lists, so I scraped the data and built a matchup comparison website.

## [2048Solver](./2048Solver)
Java and JavaScript implementation of the 2048 game with my own personal playing style implemented as an AI algorithm.

## [ArithmeticCompiler](./ArithmeticCompiler)
Building a compiler for basic strings of math — I wanted to practice working with trees and recursion.

## [TradingAlgorithm](./TradingAlgorithm)
One of my first JavaScript projects where I tried to build a model to predict when to buy crypto and stocks (don't buy crypto — I do not encourage it, I just used it for the project).

## [AdaptiSearch](./AdaptiSearch)
An adaptive search bar built fast and efficient using data structures and algorithms, designed to be dropped into any future project.

## [Swapsona](./Swapsona)
A Chrome extension that swaps a chosen word on any webpage with another word of your choosing, created to help enhance storytelling and let readers immerse themselves in a narrative.

## [ProjectHub](./ProjectHub)
A macOS menu bar app for managing and launching all personal projects in one place, with live terminal output, per-project run configurations, and custom icons.

## [AutoClaude](./AutoClaude)
I was tired of waiting for sessions to end in Claude so I decided to make a script which starts your session automatically to let you use your weekly tokens to their fullest potential.

## [PixelScreen](./PixelScreen)
A macOS screen privacy tool that pixelates your entire display with one click, making it safe to share your screen in public without exposing sensitive content.

## [ClipboardCache](./ClipboardCache)
A lightweight macOS app for saving multiple clipboard entries with custom naming, always-on-top mode, and one-click copy-back — because one Control+C was never enough.

## [TimeTeller](./TimeTeller)
I was bored so I made this. It tells the future time.
