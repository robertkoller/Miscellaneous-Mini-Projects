How to read this table
Score — composite signal strength. Higher = stronger match for the reversal pattern.
Long-term change — regression-estimated % move over ~10 months. Negative (red) is what the pattern needs.
Long-term R — how linear/consistent that trend was (0 = noise, 1 = straight line).
Recent change — regression-estimated % move over the last 3 weeks. Positive (green) is what the pattern needs.
Recent R — how consistent the recent upturn has been.
